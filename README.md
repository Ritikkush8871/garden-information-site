# 🌱 Garden Information Website

A responsive and user-friendly website designed to provide useful information about flowers, plants, their growing methods, and care instructions.

## 🌿 About the Project

The Garden Information Website helps users explore different flowers and plants and learn how to grow and care for them.

## ✨ Features

- 🌸 Flower information
- 🌱 Plant information
- 🌿 Growing instructions
- 💧 Plant care tips
- 🔍 Easy-to-use interface
- 📱 Responsive design
- 🖥️ Works across different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
